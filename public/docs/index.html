How a request flows

  1. TCP socket. accept4() hands the connection to a new thread.
  2. HTTP parser. It reads up to 8 KiB until the blank line, then checks the request line and headers against RFC 9112.
  3. Request handler. It decodes and normalizes the path, then checks with realpath() that the file is inside the document root.
  4. HTTP response. It writes the status line and headers, then streams the body with sendfile().
