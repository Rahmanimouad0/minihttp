It works.

This page was served by minihttp, a tiny HTTP/1.1 server written in C with Linux sockets and POSIX threads.

Try it

  • /docs/ is a directory with its own index.html
  • /docs is the same directory without the slash, so you get a 301 redirect
  • /style.css is served as text/css
  • /does-not-exist.html gives 404 Not Found

From a terminal

curl -i http://localhost:8080/index.html
curl -I http://localhost:8080/logo.svg
curl -i --path-as-is http://localhost:8080/../etc/passwd
printf 'BAD\r\n\r\n' | nc localhost 8080
